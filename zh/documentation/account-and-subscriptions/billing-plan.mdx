## **选择套餐**

CodeBanana 为不同用量需求提供灵活的套餐，从免费试用到高负载的个人工作场景均可覆盖。

### **Free**

Free 套餐提供 CodeBanana 的完整功能，并包含一次性试用额度。

- **价值 \$5 的免费 Token 额度**
- 在**注册当月**有效
- **20 MB** 云存储空间
- 不限制功能

<Note>
  Free 套餐的 Token 额度仅发放一次。额度将在注册当月结束时过期，且不会再次发放。
</Note>

### **Personal**

Personal 套餐面向需要专属环境和更高 Token 额度的个人开发者。

- **每月包含价值 \$25 的 Token 额度**
- **1 GB** 云存储空间
- 多种虚拟机配置：
  - **2 vCPU / 4 GB RAM**
  - **4 vCPU / 8 GB RAM**
  - **8 vCPU / 16 GB RAM**

<Note>
  Personal 套餐价格由两部分组成：虚拟机费用和每月包含的 Token 额度费用。
</Note>

### **Professional**

Professional 套餐面向负载更高的个人工作场景和大型项目。

- **每月包含价值 \$130 的 Token 额度**
- **5 GB** 云存储空间
- 可选虚拟机配置：
  - **4 vCPU / 8 GB RAM**
  - **8 vCPU / 16 GB RAM**

<Note>
  Professional 套餐价格同样由虚拟机费用和每月包含的 Token 额度费用组成。
</Note>

## **购买套餐**

选定符合需求的套餐后，可以从价格页面进行升级。

<Tip>
  **有优惠码？** 请在进入结算流程**之前**使用，否则优惠码之后不会自动生效。
</Tip>

**购买套餐：**

1. 点击工作区右上角的**升级按钮**
2. 选择套餐
3. 选择虚拟机配置
4. 选择计费周期：
   - **月付** — 按月支付
   - **年付** — 享受年度折扣
5. 点击 **Upgrade** 继续结算

<Frame>
  ![价格](/images/0715-price.png)
</Frame>

### **年付价格**

年付方式会根据以下两项费用的年度总价提供折扣：

- 虚拟机费用
- 套餐内 Token 额度费用

这意味着年付价格基于套餐的完整价值计算，而不是只根据虚拟机费用计算。

## **Token 额度与计费**

### **什么是 Token**

**Token** 用于衡量任务实际使用的模型计算量。

其中包括：

- **输入** — 提示词、上下文、文件和指令
- **输出** — Agent 回复、生成的代码和计划

任务越复杂、上下文窗口越大、模型能力越强，通常消耗的 Token 越多。

### **套餐内 Token 额度**

每种套餐都包含一定的 Token 额度：

- **Free** — 一次性提供价值 **\$5** 的 Token 额度
- **Personal** — **每月 \$25**
- **Professional** — **每月 \$130**

这些额度是套餐本身的一部分。

### **Token 充值**

套餐内 Token 额度用完后，可以通过 \*\*On-demand Usage（按需用量/充值）\*\*继续使用 CodeBanana。

个人套餐支持充值，你可以在不更改当前订阅的情况下，根据需要增加 Token 余额。

<Note>
  Team Plan 不使用个人充值。团队用量通过团队共享 Token 池管理。
</Note>

### **计费方式**

个人套餐采用以下计费结构：

1. 订阅价格包括：
   - **虚拟机费用**
   - **套餐内 Token 额度费用**
2. 套餐内 Token 额度会在**订阅续费日**重置
3. 未使用的套餐内额度**不会**结转到下一个周期
4. 套餐内额度用完后，可以通过 \*\*Top-up（充值）\*\*继续使用

### **用量提醒**

CodeBanana 提供用量提醒，帮助个人用户掌握剩余额度。

- 当套餐内剩余 Token 余额低于 **10%** 时，系统会显示提醒 **_提醒文案_**
  > Token 余额不足，你的套餐还剩 \${remaining}。立即充值或升级，确保工作不被中断。

用量提醒适用于：

- Free 套餐的 Token 额度
- 个人付费套餐包含的 Token 额度

<Note>
  如果你从 Free 升级为个人付费套餐时，剩余余额已经较低，CodeBanana 不会立即重复发送相同的低余额提醒。
</Note>
