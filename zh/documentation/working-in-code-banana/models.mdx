#### **支持的模型**

**自动模式**

自动模式会根据任务需求自动选择最合适的模型。

你无需手动选择模型。CodeBanana 会分析你的提示词，并综合考虑以下因素，为任务匹配最合适的模型：

- 任务复杂度
- 所需能力
- 预期输出质量
- 模型使用成本

<Frame>
  ![自动模式](/images/0723-automode.png "自动模式")
</Frame>

自动模式会在保证任务效果符合要求的前提下，尽可能选择更具成本效益的模型，减少不必要的模型费用。

如果你不确定应该选择哪个模型，也建议使用自动模式。它可以自动为任务匹配合适的模型，让你更轻松地开始使用。
