## **什么是 Skill**

Skill 是一种结构化模块，用于定义 Agent 应如何执行特定任务。

它通常包括：

- 一个 [**SKILL.md**](http://SKILL.md) 文件（定义 Agent 的指令和行为）
- 可选资源，例如：
  - 脚本
  - 参考资料
  - 资源文件

Skill 相当于**可复用的构建模块**，可以将一次性解决方案转化为可重复使用的能力。

#### **Skill 类型**

CodeBanana 中的 Skill 分为三类：

**公开 Skill**

- 可在 Skill Market 中获取
- 由社区创建和分享
- 可以浏览、添加到项目和分享

**私有 Skill**

- 由个人用户创建和管理
- 除非发布，否则只有你自己可见
- 可以在自己的多个项目中复用

**项目 Skill**

- **当前应用于特定项目**的 Skill
- 仅在该项目的 Agent 上下文中生效

#### **使用 Skill**

可以通过不同方式将 Skill 应用到项目：

**从 Skill Market 添加**

- 在市场中搜索相关 Skill
- 点击 **Add to Project**，将其应用到项目

**创建并复用自己的 Skill**

- 通过与 Agent 对话，将工作流打包为 Skill
- 将其上传到私有 Skill 库
- 打开项目并将其添加到当前项目，即可在多个项目中复用

**上传 Skill**

- 将 Skill 上传到你的 **Private** 库
- 上传后的 Skill 可以在不同项目中复用
- 当你希望将现有工作流或成果转化为可复用 Skill 时，可以使用此功能

#### **在哪里管理 Skill**

可以从两个入口访问 Skill：

- **Personal Center → Skills**
  - 浏览 Skill Market
  - 管理私有和公开 Skill
  - 在 Skill 列表中查看作者信息

<Frame>
  ![Skills 入口](/images/0723-manageskillall.png)
</Frame>

- **Project → Agent Config → Skills**
  - 查看和管理当前项目中已启用的 Skill
  - 添加或移除 Skill

<Frame>
  ![项目 Skill](/images/0723-skillentry.png)
</Frame>

#### **常见使用场景**

**查找 Skill 并应用到项目**

- 前往 **Skill Market**
- 搜索相关 Skill
- 点击 **Add to Project** 并选择目标项目

**将 Skill 上传到私有库**

- 前往 **Agent Config → Skills → Skill Market → Private → Upload**
- 将 Skill 上传到私有库
- 之后可以将上传的 Skill 添加到其他项目

**创建 Skill 并在多个项目中复用**

- 前往 **Agent Config → Skills → Skill Market → Private → Upload**
- 将 Skill 上传到私有库
- 在另一个项目中：
  - 前往 **Skills → Skill Market → Private → Add to Project**

**发布 Skill**

- 前往 **Skill Market → Private**
- 选择 Skill 并点击 **Publish**
- 选择 Skill 的可见范围：
  - 所有人可见
  - 仅组织内可见

**更新 Skill**

- 打开现有 Skill
- 更新其内容或资源
- 前往 Skill 库并点击 **this project** 标签页
- 点击 **update**
- 使用更新后的**版本号**发布新版本

## **Skill 为什么重要**

Skill 可以帮助团队：

- 标准化工作流
- 减少重复指令
- 在项目间分享最佳实践
- 将经验转化为可复用资产
