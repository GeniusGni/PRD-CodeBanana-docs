## **如何使用 CodeBanana**

CodeBanana 是由 AI 驱动的个人应用和网站构建工具。你不需要掌握任何编程或技术知识，只需描述想要创建的内容，其余工作由 CodeBanana 完成。

<Card title="Agent" icon="robot">
  Agent 擅长生成新项目和构建复杂功能，是 CodeBanana 的核心功能。
</Card>

Agent 就像一位**自主工作的虚拟开发者**，能够深入理解项目上下文、规划架构逻辑并执行全栈工程任务，将自然语言需求直接转化为可用于生产环境的应用。

<Card title="你可以使用 CodeBanana 创建">
  - [验证新的商业创意](https://610d4b83-888f-44a0-ab34-8f504327cc12.codebanana.app/)
  - [用来消磨时间的趣味游戏](https://typing-rain-d44fe89d.codebanana.app/)
  - 一个吐槽工作的论坛
  - [创建个人待办事项列表](https://todo-calendar-app.codebanana.app/)
  - 精美制作的 PPT
  - [个人博客](https://cce1de98-7364-49aa-ad03-e361fd52059e.codebanana.app/)
</Card>

按照以下步骤，使用 CodeBanana 创建你的第一个应用。持续进行调整，直到应用达到你期望的效果。

  立即创建你的应用
</Card>

<Steps>
  <Step title="新建项目" titleSize="p">
    前往上图所示的首页，然后点击 **Get started（开始使用），**

    点击下图所示的 **\+**，然后选择 **Create Project（创建项目）**：

    <img
      src="/images/0723-createProjectnew.png"
      alt="图片"
      title="图片"
      className="mx-auto"
    />
  </Step>
  <Step title="向 Agent 描述你的想法">
    只需用自己的语言告诉 Agent 你想创建什么，Agent 就会帮助你将想法变为现实。

    例如，你可以输入“一个德州扑克游戏”，也可以描述任何其他想法。你可以提供尽可能多的细节。第一条提示词将用于启动应用的创建过程，之后你可以随时添加更多功能或进行修改。

    <Info>
      _提示词是对你希望 Agent 执行的任务的描述。_
    </Info>

    <img
      src="/images/0723-createnewprompt.png"
      alt="图片"
      title="图片"
      className="mx-auto"
    />

    <Tip>
      你可以先使用 **My Agent** 模式完善想法，再将内容复制到 **Team Agent** 中进行构建。
    </Tip>

    提示词中可以包含文字和文件附件。完整描述所有信息后，点击发送按钮或按下 Enter，Agent 就会开始工作。
  </Step>
  <Step title="查看应用逐步成型">
    CodeBanana 会自动设计应用外观，包括选择颜色、排列按钮和组织菜单，确保界面整洁且运行流畅。

    ![快速预览](/images/0715-result.png)

    你可以在预览窗口中看到应用逐步生成，并立即点击预览、体验各项功能。任务完成后，预览窗口会自动打开。

    点击下图所示的链接，即可在新标签页中查看该页面：

    ![打开快速预览](/images/0715-previewin.png)

    ![预览标签页](/images/0715-newtabpreview.png)
  </Step>
  <Step title="完善你的应用">
    找到需要改进的地方后，可以继续与 AI 沟通，直到应用达到预期效果。

    你也可以使用截图来辅助说明想法。只需点击发送按钮旁的附件按钮，或使用 Ctrl / Command \+ V 粘贴截图。

    ![快速附加图片](/images/0715-revised.png)
  </Step>
</Steps>
