## **什么是 Team Plan**

Team Plan 是 CodeBanana 面向组织提供的灵活团队订阅方案。

团队可以配置和管理：

- 自定义席位数量
- 每个席位的虚拟机配置
- 供整个团队使用的共享 Token 池

所有计费和用量都在组织层级统一管理，管理员可以集中控制席位、计算资源、Token 消耗和成员限额。

## **购买 Team Plan**

可以通过 **Pricing → Team Plan** 购买 Team Plan。

<Frame>
  ![Team Plan 价格](/images/0418-teamplan-pricing.png)
</Frame>

### **自定义席位与共享 Token 池**

Team Plan 支持根据团队实际需求灵活配置购买内容：

- 可以自由选择席位数量
- 最少购买 **1 个席位**
- 可以自定义 Token 池金额
- Token 池没有最低金额要求
- 允许将 Token 池金额设置为 **\$0**
- Token 池由整个团队共享

### **有效期**

Team Plan 提供多种有效期选项：

- **1 个月**
- **3 个月**
- **6 个月**
- **12 个月**

### **套餐内 Token 额度**

每个席位包含固定的 Token 额度：

- **每席位每月 \$25**

Team Plan 的用量还会通过成员级限额和组织共享 Token 池进行管理。

### **虚拟机配置**

每个席位可以选择以下三种虚拟机配置之一：

- **2 vCPU / 4GB** — **每席位每月 \$45**
- **4 vCPU / 8GB** — **每席位每月 \$65**
- **8 vCPU / 16GB** — **每席位每月 \$105**

<Note>
  Team Plan 的席位价格采用与 Personal Plan 相同的虚拟机配置体系。
</Note>

## **用量入口**

购买 Team Plan 后，管理员可以通过 **Avatar → Usage** 管理席位、Token 用量和成员。

这是以下功能的主要入口：

- 团队席位用量
- Token 池余额和消耗
- 成员级用量与限额
- 续费
- 购买额外席位
- Token 充值

### **用量提醒**

CodeBanana 会针对成员级限额和组织共享 Token 池提供 Team Plan 用量提醒。

**成员按需用量限额**

- 当成员的按需用量剩余额度**不超过 10%，且不超过 \$10** 时，系统会显示提醒
- 每位用户每天最多收到**一次**此提醒
- 每位用户的提醒独立触发
- 提醒会要求用户在用量中断前联系组织 Owner 或 Admin **_提醒文案_**
  > 你即将达到按需用量限额（已使用 {usedPct}%）。请联系组织 Owner 或 Admin 提高限额，以免用量中断。

**组织共享 Token 池**

- 当共享 Token 池余额低于 **10%** 时，系统会显示提醒
- 该提醒面向组织 Owner 或 Admin，以便及时为 Token 池充值 **_提醒文案_**
  > 组织的共享 Token 预算即将用尽，目前还剩 \${remaining}。请联系组织 Owner 或 Admin 尽快充值，确保团队工作顺利进行。

### **团队用量（管理员视图）**

管理员可以查看和管理：

- 已使用席位数/总席位数
- 共享 Token 池消耗
- Token 池剩余余额
- **Add Seats（增加席位）**
- 为 Token 池执行 **Top Up（充值）**

当前限制：

- 额外购买的席位目前仅支持与初次购买 Team Plan 时**相同的虚拟机配置**
- 后续版本将支持更灵活的混合席位加购方式

有效期规则：

- 额外席位和 Token 充值与当前 Team Plan 周期采用相同的到期日期
- 如果在 Team Plan 有效期内增加席位，新增席位费用及其包含的 Token 额度均会根据该周期的剩余时间按比例计算

<Frame>
  ![增加 Team Plan 席位](/images/0520-teamplan-addseat.png)
</Frame>

### **个人用量（成员视图）**

每位成员可以查看自己的用量详情，包括：

- 个人 Token 消耗量
- 当前 Token 限额状态
- 当前虚拟机配置

## **管理员控制**

组织 Owner 和 Admin 可以管理 Team Plan 配置与用量。

### **将成员添加到 Team Plan**

<Steps>
  <Step title="进入 Usage">
    点击右上角的头像。

    在下拉菜单中选择 **Usage**，进入用量管理页面。

    <Frame>
      ![Team Plan 第一步](/images/0715-usagenew.png)
    </Frame>
  </Step>
  <Step title="Members & Quotas">
    切换到 **Members & Quotas** 标签页。
  </Step>
  <Step title="点击 Add Members">
    点击蓝色的 **Add Members** 按钮，打开成员选择弹窗。

    <Frame>
      ![Team Plan 第三步](/images/0520-teamplan-step3.png)
    </Frame>
  </Step>
</Steps>

管理员可以在已购买的席位数量范围内，将成员添加到 Team Plan。

- 成员必须已经属于该组织
- 可以直接从组织联系人中选择成员
- 席位只能在当前已购数量范围内分配

<Info>
  将成员添加到 Team Plan 前，用户必须先加入组织。只有管理员批准加入申请后，才能为其分配席位。
</Info>

<Card title="如何加入组织？" icon="arrow-right-long" href="/documentation/teams/org">
</Card>

### **计费模式**

组织 Owner 和 Admin 可以选择组织内 AI 用量费用的计费方式。

**配置位置**

- 点击右上角的**头像**
- 选择 **Billing Mode**
- 为组织选择计费模式
- 点击 **Save** 应用更改

<Frame>
  ![计费模式](/images/0715-billingmode.png)
</Frame>

**可用计费模式**

- **Owner Mode** — 组织内的所有 AI 用量均从**项目 Owner** 的额度中扣除。
- **Presenter Mode** — AI 用量根据当前 **Presenter** 自己的额度和实际用量计费。

<Note>
  只有组织 **Owner** 和 **Admin** 可以更改计费模式。所选计费模式会应用于整个组织。
</Note>

### **模型使用限制**

Team Plan 管理员可以限制每位团队成员能够使用的 AI 模型，让组织更精确地控制模型使用和成本。

**配置位置**

- 前往 **Usage → Members & Quotas**
- 在成员表格中找到 **Models** 列
- 为每位成员单独设置模型权限，或批量应用限制

<Frame>
  ![模型限制概览](/images/0520-teamplan-modellimite-overview.png)
</Frame>

**单个成员的模型限制**

- 管理员可以打开指定成员的 **Models** 选择器
- 每位成员可以设置为：
  - **All** — 所有可用模型
  - **Selected models only** — 只能使用勾选的模型
- 未选中的模型对该成员不可用

<Frame>
  ![单个成员模型限制](/images/0520-teamplan-singlemodel.png)
</Frame>

**批量模型限制**

- 管理员可以选择多位成员，也可以使用 **Select All**
- 选择成员后，管理员可以一次性应用相同的模型访问规则
- 这样可以更轻松地管理大型团队的模型权限

<Frame>
  ![批量设置模型限制](/images/0520-teamplan-batchmodel.png)
</Frame>

**筛选与可见性**

- **Members & Quotas** 顶部的 **Model Limits** 筛选器可帮助管理员快速识别已经受到模型访问限制的成员
- Skill 和项目用量仍然可见，但可用模型会根据管理员配置受到限制

**限制范围**

- 模型限制应用于**成员级别**
- 如果受限成员创建了项目，该项目中的所有人都只能使用该成员获准使用的模型
- 不可用的模型会在模型选择器中显示为禁用

![模型限制结果](/images/0715-modellimit.png)

### **修改成员套餐**

管理员可以更新：

- 每月 Token 用量限额
- 虚拟机配置
- Team Plan 成员资格

**限额控制**

- 成员只能在所配置的每月限额内使用 Token 资源
- 超出限额的用量会根据当前 Team Plan 限额和共享池设置进行处理

**升级虚拟机**

- 支持升级虚拟机
- 更改立即生效

如果共享 Token 池余额充足：

- 升级费用可以从 Token 池中扣除
- 额外席位费用也可以从 Token 池中扣除

**降级虚拟机**

- 目前**不支持**降级虚拟机

**移除成员**

- 管理员可以移除 Team Plan 成员
- 被释放的席位之后可以在已购席位数量范围内重新分配给其他成员

## **续费**

Team Plan 支持在到期前续费。

管理员可以在 **Usage** 页面点击 **Renew**，直接续订套餐。

这样可以确保团队持续使用席位和 Token 池，不会中断。

---

## **企业付款**

Team Plan 还支持签约客户通过企业线下方式付款。

该选项面向不直接通过前端管理采购的企业客户。

如需企业付款支持，请联系 CodeBanana 团队。

## **包含的权益**

Team Plan 包含以下权益：

- **每席位每月 \$25 Token 额度**<br />每个席位包含固定的每月 Token 额度
- **灵活的席位管理**<br />管理员可以随时管理 Team Plan 成员，并在之后增加席位或为 Token 池充值
- **团队用量限额控制**<br />管理员可以设置成员每月 Token 用量限额，更好地控制支出
- **自定义虚拟机配置**<br />可以根据需要升级成员的虚拟机配置
- **随时充值，按需使用**<br />Token 池可以随时充值，没有最低金额限制
- **共享按需 Token 用量**<br />团队成员共享同一个 Token 资源池，从而更灵活地分配团队用量

## **版本过渡说明**

新版 Team Plan 将替代之前的版本。

现有 Team Plan 用户不受此次过渡影响。在现有权益到期或全部用完之前，他们可以继续使用当前 Team Plan 权益。

## 常见问题

以下是有关 Team Plan 的常见问题解答。

<AccordionGroup>
  <Accordion title="在哪里可以购买 Team Plan？">
    可以通过 **Pricing → Team Plan** 购买 Team Plan。
  </Accordion>

  <Accordion title="购买 Team Plan 时可以自行选择席位数量吗？">
    可以。Team Plan 支持自定义席位数量，最少购买 **1 个席位**。
  </Accordion>

  <Accordion title="Team Plan 提供哪些有效期？">
    Team Plan 支持 **1、3、6 和 12 个月**的有效期。
  </Accordion>

  <Accordion title="Token 池有最低充值金额吗？">
    没有。Token 池金额可以完全自定义，也允许设置为 **\$0**。
  </Accordion>

  <Accordion title="Token 池由整个团队共享吗？">
    是。Token 池由 Team Plan 中的所有成员共享，并可按需使用。
  </Accordion>

  <Accordion title="套餐内 Token 额度用完后会怎样？">
    Team Plan 可以根据当前组织 Token 池和成员限额配置继续提供用量。
  </Accordion>

  <Accordion title="可以为不同成员分配不同的虚拟机配置吗？">
    可以。每个席位都可以单独配置，管理员之后也可以为个别成员升级虚拟机配置。
  </Accordion>

  <Accordion title="可以降级虚拟机配置吗？">
    不可以。目前支持升级虚拟机，但不支持降级。
  </Accordion>

  <Accordion title="管理员之后可以增加席位吗？">
    可以。管理员可以在 Usage 页面使用 **Add Seats**。目前，额外席位必须采用与初次购买时相同的虚拟机配置。
  </Accordion>

  <Accordion title="如果在 Team Plan 有效期中途增加席位，会怎样计算？">
    如果在 Team Plan 有效期内增加席位，新增席位会沿用当前 Team Plan 的到期日期。

    额外席位费用及其包含的 Token 额度都会**根据当前周期的剩余时间按比例计算**。

    例如，如果 Team Plan 有效期为 **6 月 1 日至 6 月 30 日**，并在 **6 月 15 日**增加一个席位，则新增席位将在 **6 月 30 日**到期，席位费用和套餐内 Token 额度也会根据剩余时间按比例计算。
  </Accordion>

  <Accordion title="管理员之后可以为 Token 池充值吗？">
    可以。管理员可以在 Usage 页面使用 **Top Up**，随时为共享 Token 池充值。
  </Accordion>

  <Accordion title="席位升级或虚拟机升级可以从 Token 池中支付吗？">
    可以。如果共享 Token 池余额充足，额外席位费用和成员虚拟机升级费用都可以从 Token 池中扣除。
  </Accordion>

  <Accordion title="管理员如何将成员添加到 Team Plan？">
    只要成员已经加入组织且有可用的已购席位，管理员就可以通过 **Usage → Members & Quotas** 添加成员。
  </Accordion>

  <Accordion title="Team Plan 如何使用成员 Token 限额？">
    Team Plan 支持成员级 Token 限额，让组织更精确地控制用量。当成员接近所配置的按需用量限额时，CodeBanana 可能会根据当前提醒规则显示提示。限额处理方式和可用用量还取决于组织共享 Token 池的配置。
  </Accordion>

  <Accordion title="管理员可以限制团队成员使用哪些 AI 模型吗？">
    可以。在 **Usage → Members & Quotas** 中，管理员可以通过 **Models** 列配置每位成员的模型访问权限。成员可以使用所有模型，也可以只使用选定的模型。如果受限成员创建了项目，该项目中的所有人都只能使用该成员获准使用的模型。
  </Accordion>

  <Accordion title="Team Plan 什么时候会显示用量提醒？">
    Team Plan 针对不同类型的用量采用不同的提醒规则。

    - 当成员的按需用量剩余额度**不超过 10%，且不超过 \$10** 时，成员会收到提醒
    - 当共享 Token 池余额低于 **10%** 时，组织 Owner 或 Admin 会收到提醒
  </Accordion>

  <Accordion title="在哪里可以续订 Team Plan？">
    可以在到期前进入 **Usage** 页面，点击 **Renew** 续订 Team Plan。
  </Accordion>

  <Accordion title="企业客户可以使用线下付款，而不是通过前端购买吗？">
    可以。企业客户可以联系 CodeBanana 团队获取线下付款支持。
  </Accordion>

  <Accordion title="旧版 Team Plan 的现有用户会失去权益吗？">
    不会。现有 Team Plan 用户不受此次过渡影响。在当前权益到期或全部用完之前，他们可以继续使用现有 Team Plan 权益。
  </Accordion>
</AccordionGroup>
