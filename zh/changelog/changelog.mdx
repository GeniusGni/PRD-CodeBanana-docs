<Update label="07/28/2026">
  ## **Team Plan 更新**

  本次更新进一步增强了 Team Plan 的管理能力，使组织在计费、配额管理和成员配置方面更加灵活高效。

  ### **共享 Token 池**

  Team Plan 现已支持**共享 Token 池**。

  对于现有 Team Plan 组织，升级后，所有成员剩余的套餐内 Token 将自动迁移至共享 Token 池。组织成员将统一从共享 Token 池中消耗 Token，无需再使用各自独立的配额。

  ### **批量成员管理**

  Team Plan 现已支持**批量配置成员设置**。

  管理员可以一次性为多个成员配置 Token 上限、可用模型、VM 配置以及其他 Team Plan 设置，大幅提升大规模团队的管理效率。

  ### **模型管理优化**

  模型管理能力进一步增强，支持**可复用的模型配置模板**。

  管理员现在可以：

  - 将模型列表保存为可复用的模板
  - 批量将模型模板应用到多个成员
  - 为模板配置默认模型，并支持将 **Auto** 模式设为默认模型

  这些改进能够帮助组织更高效地统一模型配置和管理策略。

  ### **支持 VM 降级**

  Team Plan 现已支持**虚拟机降级**。

  组织可以根据团队实际需求，更灵活地调整虚拟机规格，进一步优化资源配置。

  ### **Team Plan 续费优化**

  Team Plan 续费现已支持**直接使用 Budget Balance（共享 Token 池余额）支付**。

  此前，Budget Balance 仅可用于新增席位和升级虚拟机。现在也可用于 Team Plan 续费，进一步统一了组织的支付和计费体验。
</Update>

<Update label="07/14/2026">
  ## **Personal Agent、项目管理与消息体验更新**

  本次发布对 **Personal Agent**、项目自定义、模型可用性、成员管理、消息转发和多项稳定性进行了重要改进。

  ## **支持项目头像**

  项目现在支持自定义头像。

  用户可以通过以下路径配置项目头像：

  **聊天区域 → 右上角“…” → Settings**

  这样可以在不同协作场景中更加灵活地识别和管理项目。

  ## **Personal Agent 改进**

  **Personal Agent** 的项目与用量感知能力得到显著增强。

  Personal Agent 现在可以查询和总结：

  - 项目数据、成员信息和新加入的项目
  - 个人用量和消耗数据
  - Team Agent 和 Private Ask 消息（之前仅支持 Discussion 消息）
  - 每日、每周和每月摘要
  - 项目活动数据
  - 按模型划分的用量明细

  这些更新提升了 Personal Agent 作为个人工作区助手的能力，帮助用户了解项目进度、活动和用量模式。

  ## **支持新模型**

  CodeBanana 现已支持更多模型：

  - **GPT-5.6-sol**
  - **GPT-5.6-terra**
  - **GPT-5.6-luna**
  - **Claude Sonnet 5**

  新增模型为不同开发场景提供了更多选择。

  ## **Members 弹窗改进**

  Members 弹窗已更新，提供更完善的管理能力。

  新增更新包括：

  - 改进群组 Admin 的管理员配置
  - Agent 访问权限设置
  - 通过 **Add Robot** 管理机器人，包括显示和复制 Webhook URL
  - 改进 **Add Agent** 弹窗，新增 **Added Agents** 筛选分类

  后续版本还会继续改进视觉体验。

  ## **消息转发改进**

  消息转发现已支持 **i18n** 和引用消息。

  转发消息现在会保留原始引用关系，并支持多语言内容处理，让不同语言环境下的共享对话更易理解。

  ## **Agent 与 Skill 改进**

  修复 HTML 相关任务未优先加载 **single-file-html Skill** 的问题。

  HTML 生成任务现在会默认稳定触发 HTML Skill，提高 HTML 生成质量。

  修复 Read File 工具无法正确处理 **TicNote** 分享链接的问题。

  TicNote `shareDetail` 链接现在会自动转换为正确的 `shareDetailReal` 格式，以便读取。

  ## **问题修复与稳定性改进**

  本次发布修复了消息、分享、问卷、头像和引用等多方面问题。

  - 修复转发消息可能包含错误 `message_id`，并显示上一条消息的问题
  - 修复分享场景下 HTML 详情内容可能返回空值的问题
  - 修复问卷返回页面链接可能包含不必要语言路径前缀的问题
  - 修复群组头像校验逻辑，使文本头像模式支持空 `avatarUrl` 值
  - 修复无法正确显示上一页引用消息的问题

  这些改进增强了消息一致性、分享可靠性和整体产品稳定性。
</Update>

  本次发布更新了国际化、默认模型设置、消息转发、@Mention 体验、导航交互、文件树显示和 GitLab 项目创建。

  消息显示和交互中的转发体验得到改进。

  更新包括：

  - 改进转发标题和消息提示
  - 为转发消息添加来源群组信息
  - 修复转发消息中的聊天记录和图片可能被错误设置为可点击的问题

  **@Mention** 在文件选择、输入行为和稳定性方面得到显著改进。

  - 使用 Command \+ Enter 时换行错误
  - 无法正确触发 @Mention
  - 提及后插入位置错误

  其他稳定性改进包括修复 Mention 系统中的 React #300 错误、弹窗定位问题、涉及 BR 标签的光标计算问题、@Mention 后换行无效以及偶发崩溃。

  @Mention 项目列表现在也会实时刷新。

  ## **交互改进**

  导航和切换行为得到优化。

  **Sidebar**、**ChatList** 和 **ProjectList** 新增防抖处理，减少频繁切换聊天和项目造成的不必要请求。

  ## **文件树改进**

  文件树界面在视觉上得到优化。

  这些更新提高了可读性，并让项目文件导航更加一致。

  ## **GitLab 项目创建改进**

  修复创建项目过程中退出 GitLab 后，已保存密码可能不可用的问题。

  GitLab 项目导入和创建流程现在更加稳定。

  ## **Team Plan、组织管理与 Agent 更新**

  本次发布更新了 Team Plan 成员管理、模型控制、组织联系人、用户引导体验、Agent 能力和 IM 集成，并包含多项稳定性改进。

  ## **Team Plan 成员管理与模型设置**

  Team Plan 现在支持更灵活的成员级配置。

  组织现在可以根据组织架构，通过以下路径为成员配置不同的可用模型和 Token 限额：

  **Usage → Members & Quotas → Batch Settings**

  Admin 还可以通过以下路径管理模型配置：

  **Usage → Members & Quotas → Manage Models**

  支持的能力包括：

  - 将模型列表保存为模板
  - 自定义模型排序
  - 为成员设置默认模型

  本次发布还修复了 Team Plan 成员的 Token 限额设为 **0** 后无法再次更新的问题。

  ## **组织联系人与管理更新**

  Contacts 体验得到改进，支持更复杂的组织架构，包括一人管理多个部门，以及同一部门中的成员拥有不同直属上级等情况。

  新增能力包括：

  - 通过 **Contacts → Department list → Edit** 设置部门负责人
  - 通过 **Contacts → Member list → Edit** 设置直属上级
  - 在成员资料卡中显示 **Direct Manager** 信息

  这些更新提高了汇报关系和组织职责的可见性。

  ## **系统通知更新**

  全局系统消息类型得到扩展。

  组织加入通知和好友邀请通知现在会全局显示，不再受组织筛选限制。

  ## **问卷页面本地化**

  问卷相关页面现在支持多语言显示。

  这提高了不同语言环境下用户的可访问性。

  ## **好友邀请通知**

  好友邀请流程现在提供双向通知。

  好友邀请被接受或拒绝后，原始发送者会收到相应的系统通知。

  ## **模型选择持久化**

  CodeBanana 现在会记住用户选择的模型。

  用户再次进入产品时，系统会自动恢复之前选择的模型。

  ## **预设项目配置更新**

  预设项目现在支持参数级配置。

  不同类型的预设项目现在可以定义用户能否邀请成员、添加 Agent，以及其他项目专属行为。

  预设项目还新增以下保护：

  - 预设项目不能被删除或解散
  - 改进预设项目头像，包括 **TN Subscription**、**Personal Agent** 和 **Approval Workflow** 项目

  ## **Personal Agent 更新**

  **Personal Agent** 体验得到改进。

  更新包括：

  - 改进头像显示
  - 扩大数据查询范围

  Personal Agent 现在可以查询 **Team Agent**、**Private Ask** 和 **Discussion** 上下文中发送的消息。

  历史 Personal Agent Skill 仍在逐步更新。

  ## **Agent 更新**

  Agent 工作流新增多项保护和改进。

  跨项目 Discussion 委派现在受到限制，以确保正确的项目级聊天边界，防止意外共享上下文。

  Scheduler 成本跟踪现在包含任务创建者信息，提高用量归属和成本可见性。

  ## **IM 集成更新**

  IM Channel 集成获得多项改进。

  更新包括：

  - 修复并优化 Channel 图标
  - IM 页面现在会保留所选引擎和模型设置
  - 修复 QQ、Telegram 和其他受支持 Channel 的消息回复限制

  ## **Discussion 回复改进**

  修复用户引用消息时，Discussion 无法正确回复的问题。

  Discussion 现在能够更可靠地处理引用内容。

  ## **好友邀请通知修复**

  修复好友邀请接受/拒绝通知可能包含错误组织 ID 的问题。

  通知现在会正确发送给目标用户。

  ## **CBBot 项目权限修复**

  修复成员通过邀请链接或直接邀请加入 CBBot 创建的项目时，可能错误获得 Admin 权限的问题。

  CBBot 创建的项目中，新成员现在默认以普通 Member 权限加入。

  ## **Private Ask 队列显示修复**

  修复 **Private Ask** 在等待期间可能显示其他用户队列信息的问题。

  请求处理期间，用户现在只能看到自己的队列状态。
