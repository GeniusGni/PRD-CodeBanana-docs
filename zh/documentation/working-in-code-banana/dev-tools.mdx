### **终端（Terminal）**

内置终端支持开发者直接与项目环境交互。

- 在项目的运行环境中执行命令
- 适用于：
  - 安装依赖
  - 运行脚本
  - 调试问题
- 支持更高级或自定义的开发工作流
- 可以在文件管理栏中打开开发工具

### **服务（Service）**

Service 面板用于管理运行中的进程和活跃端口。

- 查看所有**运行中的服务和端口**
- 服务异常时重启虚拟机环境
- 根据需要终止指定进程或释放端口

这些功能有助于确保应用稳定运行，并在出现问题时快速恢复。

<Frame>
  ![服务](/images/0723-devservice.png)
</Frame>

### **Git 状态**

Git Status 提供版本控制状态和基础操作。

- 查看当前文件变更
- 通过 **Save** 操作创建提交
- 查看提交历史：
  - 检查之前的版本
  - 根据需要恢复到指定提交

团队可以直接在工作区中跟踪变更，并维护清晰的开发历史。

### **部署（Deploy）**

Deploy 支持将项目发布为一个**长期有效且可分享的链接**：

- 生成不会过期的稳定 URL
- 项目发生变化时自动更新
- 最适合：
  - 静态网站
  - 轻量级应用

建议先通过预览功能确认项目效果，再进行部署。
